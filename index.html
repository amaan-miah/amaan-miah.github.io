RAI
Independent project
AWS Summit London 2026
April 2026
↗ github.com/amaan-miah/rai

A serverless RAG pipeline that answers questions from internal documentation in under 5 seconds. Built on AWS without LangChain — every layer written in plain Python so every decision is visible and debuggable. Demoed at AWS Summit London 2026 to a CTO who connected on LinkedIn and a startup founder who arranged a follow-up call.

Architectural decisions
S3 over Pinecone Negligible latency difference under 1,000 chunks. Removes external dependency entirely. Switch to OpenSearch at 10,000+ chunks.
Lambda over EC2 Usage is unpredictable. Lambda scales to zero between requests. No idle compute cost.
RAG over fine-tuning Documents change constantly. RAG keeps knowledge live without retraining the model.
Plain Python over LangChain Full visibility into embedding, retrieval, and generation. No abstraction hiding failure modes.
Next: Terraform Infrastructure currently deployed manually. Adding Terraform so the entire stack deploys in one command on any AWS account — industry standard for reproducible infrastructure.

PROJECT_02
Ndeko
FME Copilot
MongoDB Agentic Evolution Hackathon
May 2026
Private repo — operational data

A voice-first multimodal AI agent for telecom field engineers in the DRC. Engineers call it during a site failure — it pulls site history from MongoDB, asks for a photo of the energy meter, reads it via LLM vision, searches SOP manuals using vector search, and gives a hands-free diagnosis. Built using real operational data from a live telecom business. Demoed to judges including a Member of Technical Staff at xAI. Matheus Guimarães (Sr. Developer Advocate, AWS) said the project could probably be sold and that the team looked like a Silicon Valley team.

Architectural decisions
LangGraph over LangChain Field diagnostics are stateful. Agent pauses while engineer walks to equipment, then processes async photo. State machine, not a prompt chain.
MongoDB Atlas for everything Replaced Pinecone + Redis + PostgreSQL with one service. Vector search, document storage, and LangGraph session checkpointing from one connection string.
WebRTC over HTTP/WebSocket Sub-500ms voice latency required for natural conversation. Traditional HTTP introduces too much delay for real-time field diagnosis.

PROJECT_03
GraphMind
Graph RAG Agent
Hack Night London — Tessl
May 2026 · Demoed to judges via video submission
↗ github.com/amaan-miah

A knowledge graph RAG agent built at Tessl's hack night in London. Instead of searching flat document chunks, data lives as a connected graph in Neo4j. The agent traverses relationships — finding not just relevant nodes but everything connected to them. Richer context than traditional vector search without increased latency.

Architectural decisions
Neo4j over vector DB Graph relationships carry meaning that flat embeddings lose. "Who directed The Matrix" retrieves the director, their other films, and their collaborators — not just the movie.
Kimchi for LLM inference OpenAI-compatible endpoint pointing at open-source models. Same interface as Claude/GPT-4, zero API cost, no usage limits during rapid prototyping.
Neo4j Python Kimchi Tessl skills Cypher OpenAI API
